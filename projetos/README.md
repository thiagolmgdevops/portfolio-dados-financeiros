# Projetos

Cada projeto tem uma pasta própria neste formato:

```
NN-nome-do-projeto/
├── README.md   ← pergunta de negócio, dados, solução, painel, insights, o que aprendi
├── dados/      ← dados extraídos do Banco Central
├── scripts/    ← código da extração
├── powerbi/    ← arquivo .pbix
└── imagens/    ← capa e prints do painel
```
