# Portfólio de Dados – Mercado Financeiro

Projetos de análise de dados aplicados ao mercado financeiro brasileiro, construídos com **dados públicos e reais do Banco Central do Brasil**.

## Sobre mim

Sou formado em Marketing e estou fazendo a transição de carreira para **Análise de Dados no setor financeiro**.
Tenho as certificações **ANBIMA CPA, CPRO-I e CPRO-R** e formação para atuar como gerente PJ em bancos, o que me dá uma base sólida em produtos financeiros, crédito e regulação.

Juntando essas duas bagagens, meu foco é transformar dados em decisões de negócio em áreas como:

- **Crédito e risco**: inadimplência, concessão, carteiras PJ e PF
- **CRM e inteligência de clientes**: segmentação, comportamento e campanhas
- **Indicadores macroeconômicos**: Selic, inflação, juros e seus efeitos no crédito

## Ferramentas

- **Power BI** (modelagem de dados, DAX, painéis)
- **Excel**
- **SQL**

## Como os projetos são organizados

Cada projeto fica em [`projetos/`](projetos/), em uma pasta própria, com:

- **Pergunta de negócio**: o problema que a análise responde
- **Dados**: fonte, códigos das séries do Banco Central e data da extração
- **Solução**: modelo de dados e principais medidas
- **Painel**: prints do resultado
- **Insights**: as conclusões, com números
- **O que aprendi**

## Fontes de dados

- [SGS – Sistema Gerenciador de Séries Temporais](https://www3.bcb.gov.br/sgspub/) (Banco Central)
- [Portal de Dados Abertos do Banco Central](https://dadosabertos.bcb.gov.br/)
- [IF.data](https://www3.bcb.gov.br/ifdata/) (dados das instituições financeiras)
